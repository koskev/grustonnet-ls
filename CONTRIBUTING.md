# Contributing to this project

## Commit messages
Your commit messages must adhere to the [conventional commits](https://www.conventionalcommits.org) convention

## Commit signing
All your commits have to be signed. Either with GPG or SSH.


To sign your commits using ssh just run these commands
```
git config --global gpg.format ssh
git config --global user.signingkey ~/.ssh/<your ssh key>.pub
git config --global commit.gpgsign true
```
